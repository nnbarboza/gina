# img/charlar/

Imágenes de los temas de Charlar.

En la pestaña **Prompts_Charlar** del Sheet, la columna `foto` acepta:
- El **nombre del archivo** que vive aquí, ej. `dinosaurios.webp` → se sirve como `img/charlar/dinosaurios.webp`.
- Una **URL completa** (`https://…`) por compatibilidad con lo antiguo.

Para añadir una imagen nueva: se pone el nombre en el Sheet y el archivo se
commitea en esta carpeta. Formato recomendado: `.webp`, ~800px de lado.
